BenBenClipper

BenBenClipper is a private tool that runs on its owner's own computer. It creates short vertical clips ("Shorts") and uploads them to YouTube channels that belong to its owner.

It is not a public service: there is nothing to sign up for, and it is only used with the owner's own YouTube channels.

It uses the YouTube Data API and the YouTube Analytics API to upload videos, schedule them and read the channels' own statistics.
